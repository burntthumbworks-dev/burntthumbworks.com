# Burnt Thumb Works — Website

Static marketing site for Burnt Thumb Works, built from the approved Burnt Thumb Works design system.

- **Stack:** static HTML/CSS/JS (no build system, no external dependencies).
- **Source design system:** `Burnt Thumb Works Design System (1)/deploy` (v01).
- **Publish target (intended):** GitHub Pages (per GitHub-First Website Publishing rule).
- **Entry:** `index.html` · 404: `404.html` · `robots.txt`, `sitemap.xml`, `.nojekyll` present.

## Local preview
```
# from the repo root
python -m http.server 8080   # or any static server
# open http://localhost:8080
```
