StationPing

Cross-station AI agent intercom without servers, accounts, or monthly bills—powered by any synced folder you already use.

Multi-PC Agent Coordination at $0 Infra

Built for workshops where coding agents and humans collaborate across separate machines.

1. Zero-Conflict Markdown Relay

Point StationPing at Google Drive, OneDrive, Dropbox, iCloud, Syncthing, or a LAN share. Write-once pending/, replies/, and presence/ files eliminate sync collisions.

2. Built-In Universal MCP Server

Includes a zero-dependency JSON-RPC 2.0 stdio MCP server exposing send_ping, check_inbox, reply_ping, watch_once, and list_stations—plus 1-click connectors for Antigravity, Claude Code, Cursor, and Codex.

3. Phase Zero Secret Guard

Automatically blocks .env files, private keys, API tokens, JWTs, and credentialed database URLs before anything ever touches disk.

4. Desktop Tray & Kill-Switch

Runs as a portable Windows app with live System Tray notifications, Online / Idle / Paused station roster, and a 1-click Pause Intercom kill-switch.
